# 📊 Python Projects Using Matplotlib

A collection of beginner-friendly Python scripts that demonstrate how to create different types of visualizations using Matplotlib. These mini projects are great for learning how to plot data, style charts, and explore real-world data trends.

---

## 📁 Projects Included

| Filename               | Description |
|------------------------|-------------|
| `line_plot.py`         | 📈 Simple line chart from sample data |
| `bar_chart.py`         | 📊 Bar chart comparing values (e.g., sales) |
| `pie_chart.py`         | 🥧 Pie chart showing proportions |
| `histogram.py`         | 📚 Histogram showing distribution of random values |
| `weather_plot.py`      | 🌦️ Plotting weekly temperature trends |
| `csv_plotter.py`       | 📁 Reads a CSV-like dataframe and plots data |
| `live_plot_demo.py`    | 📡 Real-time updating plot with random data |
| `stock_price_plot.py`  | 💹 Stock price visualization using yfinance |

---

## ▶️ How to Run

1. Make sure you have Python and the required libraries:
   ```bash
   pip install matplotlib pandas yfinance
   ```

2. Run any script:
   ```bash
   python bar_chart.py
   ```

---

## 🧠 Skills Practiced

- Data Visualization with Matplotlib
- Customizing Charts (titles, labels, legends)
- Handling DataFrames with Pandas
- Real-time Plot Animation
- Accessing Stock Data with yfinance
